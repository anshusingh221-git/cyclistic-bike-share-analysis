# Case Study 1: How Does a Bike-Share Navigate Speedy Success?
**Author:** Anshu Kumari  
**Credential:** Google Data Analytics Professional Certificate  

## 📌 Project Overview
This capstone project is part of my Google Data Analytics Professional Certificate. In this fictional case study, I work as a Junior Data Analyst for **Cyclistic**, a bike-share company based in Chicago. 

### 🎯 The Business Task
The Director of Marketing (Lily Moreno) believes that the company’s future growth depends on maximizing annual memberships. My specific task is to analyze historical trip data to understand **how annual members and casual riders use Cyclistic bikes differently**. These insights will help design marketing strategies to convert casual riders into profitable annual members.

## 🛠️ Data Analysis Process & Tools
To solve this business problem, I followed the standard data analysis framework: **Ask, Prepare, Process, Analyze, Share, and Act**.

*   **Excel / Google Sheets:** Initial data exploration, calculating `ride_length`, and determining `day_of_week`.
*   **SQL (BigQuery/PostgreSQL):** Merging large datasets (12 months of historical trip data) and running descriptive queries.
*   **Tableau / Python (Pandas & Matplotlib):** Creating data visualizations to identify trends and patterns.
